# Раунды — онлайн-арена дуэлей

Динамичная 2D-дуэль с картами, боссами и онлайн-мультиплеером.
Всё работает в браузере: клиент и сервер нет, плеер — статический сайт.

## Что уже работает

- **Онлайн-дуэль** по 6-значному коду комнаты: один играет как **хост**, второй как **гость**.
- **WebRTC P2P** (данные передаются прямо между браузерами, не через ваш сервер).
- **Сигналинг** — бесплатный облачный сервер [PeerJS](https://peerjs.com) (встроен в файл, чтобы хранить проект в одном `index.html`).
- **STUN** (Google + Cloudflare) для обхода NAT.
- Режим: меню → настройки → бой с ботом или онлайн-дуэль → раунды (2–7) → выбор карт → победа/поражение → реванш.
- 12 персонажей, 12 бонусов, 6 боссовых арен, 3 режима сложности, куча звуков.

## Что нужно для работы на GitHub

Никакого сервера. Достаточно разместить `index.html` на **GitHub Pages** (HTTPS).
Всё это уже встроено в файл: стили, скрипты, PeerJS (MIT), больший код игры.

## Как разместить на GitHub

### 1. Создайте репозиторий на GitHub

1. Откройте **GitHub → New repository**.
2. Название, например `rounds-arena` (любое).
3. Выберите **Public** (так Pages сможет отдать сайт).
4. **Не добавляйте** `README`, `.gitignore` или `LICENSE` (иначе в ветку попадёт лишнее),
   пока что. Достаточно иметь `index.html`.

### 2. Загрузите файл в репозиторий

Самый простой способ — через веб-интерфейс:

1. Зайдите в ваш пустой репозиторий на GitHub.
2. В левой части нажмите **Add file → Upload files**.
3. Загрузите `index.html` (из `C:\Users\vitalik\Desktop\555\index.html`).
4. Внизу напишите коммит, например `Initial release`, и нажмите **Commit changes**.

### 3. Включите GitHub Pages

1. Откройте **Settings** → внизу **Pages**.
2. В **Branch** выберите `main` (или `master`), в **Folder** оставьте `/ (root)`.
3. Нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/название-репозитория/`

Например, `https://vitalik.github.io/rounds-arena/`.

### Альтернатива: залить через командную строку

## Как играть в онлайн

1. **Хост** создаёт комнату в меню → «Онлайн-дуэль». Проходит:
   - Меню → настройки → кнопка «ОНЛАЙН-ДУЭЛЬ С ДРУГОМ».
   - Хост получает 6-значный код и ссылку (копируется автоматически).
2. **Гость** открывает ссылку или вводит код. Гость подключается как вторая фигура.
3. Нажмите «Матч начался» (или ждите, пока гость нажмёт «Начать»).
4. Оба игрока управляют своими жителями: **A/←→ стрелки** (движение),
   **мышь по экрану** (поворот + выстрел), **Space/↑/W** (прыжок), **П** (пауза, только оффлайн).
5. Чтобы закончить матч и вернуться в меню, нажмите «Выйти» (или `Esc`).

### Важно

- **Хост должен держать вкладку открытой**: соединение живёт только пока открыта страница хоста.
- Лучше играть через **мобильный интернет** или разные сети, а не один VPN/прокси.
- Бесплатный PeerJS-сервер бывает шумный. Если подключение падает,
  обновите страницу или создайте новую комнату.

## Как работает сеть (коротко)

- Хост и гость подключаются к PeerJS-серверу для обмена адресом (сигналинг).
- После этого пакеты идут напрямую между браузерами (WebRTC DataChannel, JSON).
- Гость получает снимки игрового состояния (позиции, HP, враги) и затирает свою копию
  интерполяцией; хост фиксирует сеть по таймауту.
- Для наглядности время рисуется по `performance.now()` внутри снепа.
